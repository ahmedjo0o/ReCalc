How to use reCalc — Quick Tutorial / كيفية استخدام التطبيق — دليل سريع

1

Start — Set number of people / ابدأ — حدد عدد الأشخاص

Enter how many people are splitting the receipt, then press Go. This creates name fields for each person.

أدخل عدد الأشخاص الذين سيشتركون في الفاتورة ثم اضغط ابدأ. سيقوم التطبيق بإنشاء حقول إدخال لكل شخص.

2

Add names / أدخل الأسماء

Fill each person's name or use the favorites list. Then press Next.

اكتب أسماء الأشخاص أو اختر من قائمة المفضلات. ثم اضغط التالي.

3

Totals & discount / الإجمالي والخصم

Enter the Total Receipt Value, the Sub-total, and the discount if applicable.

أدخل إجمالي الفاتورة، والمجموع الفرعي، والخصم إذا وُجد.

4

Assign orders / وزّع الطلبات

Enter the order value for each person. The app will split VAT, service, and discount proportionally.

أدخل قيمة طلب كل شخص. سيقوم التطبيق بتقسيم الضريبة والخدمة والخصم بشكل نسبي.

5

Calculate & share / احسب وشارك

Press Calculate to view each person’s final cost. Use Share or Export to save or send the results.

اضغط احسب لعرض المبلغ النهائي لكل شخص. يمكنك استخدام مشاركة أو تصدير لحفظ أو إرسال النتائج.
